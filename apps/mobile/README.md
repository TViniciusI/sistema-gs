# GS Campo (demonstração)

Aplicativo do técnico. Login, agenda, registros da OS e anexo do certificado Excel.

```bash
cd apps/mobile
flutter pub get
flutter run -d chrome
```

Acesso da demo:

- usuário `felipe@gssolucoestec.com.br`
- senha `demonstracao`

Fluxo:

1. Entrar no app
2. Abrir **GS 036/26**
3. Preencher registros (horários, descrição, fotos, assinatura)
4. **Anexar planilha do certificado** (ou usar a planilha de demonstração)
5. **Enviar anexo ao escritório**
6. No sistema web, abrir **Certificados**
